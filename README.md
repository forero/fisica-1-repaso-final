# Física 1: repaso para el examen final

Preguntas de selección múltiple para repasar antes del examen final de Física 1
(FISI-1518, Universidad de los Andes).

- [`parte-1.pdf`](parte-1.pdf): 17 preguntas de cinemática, leyes de Newton,
  trabajo y energía, y momentum.

La presentación termina con una lámina en blanco y, después de ella, las
respuestas con una línea de justificación.

Las preguntas provienen de un examen final de 2019; aquí solo están las que se
entienden sin necesidad de una figura.
